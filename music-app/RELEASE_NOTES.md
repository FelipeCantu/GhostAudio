# Ghost Music App - Beta 0.1.0 Release

## 🚀 New Features
- **Automatic CD Detection**: The Importer now instantly scans and detects available optical drives as soon as you open the page—no manual refresh required.
- **Seamless Desktop Experience**: The backend logic is now integrated natively into the app using Electron. No more separate backend servers or processing!
- **One-Click Import**: Select your drive and start ripping tracks with a single click.

## ✨ Improvements
- **Performance**: Optimized startup time and process management.
- **Stability**: Robust error handling ensuring the ripping engine is always ready when you are.
- **Security**: Handle and allow for hosting and packages
